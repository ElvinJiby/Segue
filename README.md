## About
Online Video Game Music Marketplace</br>
Developed in Spring Boot using MVC architecture</br>

Features Spring Security Authentication - Support for Admin and Customer roles, as well as a Login/Registration system</br>
Admins can see register users, add/edit/hide products, and manage user orders</br>
Customers can view products and order them. Working cart feature to specify wanted quantity and relevant actions (removing from cart)</br> 

## Technologies Used
Spring Boot</br>
Thymeleaf</br>
Spring Security</br>
MySQL
